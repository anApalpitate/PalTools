# PalTools

PalTools 是一款面向《幻兽帕鲁》玩家的本地图鉴与配种辅助工具，帮助玩家更快查找帕鲁资料、验证配种结果，并逐步整理自己的配种方案。

工具可离线使用，不需要登录账号，也不会读取或修改游戏存档。

## 下载与运行

Windows 用户可从 [GitHub Releases](https://github.com/anApalpitate/PalTools/releases) 下载 `PalTools-0.1.0-win-x64.exe`。这是免安装便携版，下载后可直接运行；首次启动若出现 Windows 安全提示，请先核对下载来源和版本信息。

## 主要用途

- **查资料**：集中查看帕鲁的属性、工作适性、技能、掉落物和各项能力数值。
- **选帕鲁**：按名称、编号、属性和工作适性筛选，再按图鉴编号或能力数值升序、降序排列，快速找到符合需求的帕鲁。
- **查配种结果**：选择一只亲本可浏览并筛选它参与的全部配方；选择两只亲本可直接查看精确配种结果。
- **获取目标帕鲁**：指定目标子代，查看所有可用的亲本组合，并标记想继续比较的配方。
- **整理配种方案**：使用全窗口固定槽位配种森林组织方案，从可完全隐藏的覆盖侧栏加入帕鲁，并支持自动保存、编辑工具、撤销/重做及 JSON 导入导出。
- **切换界面主题**：在七套固定主题之间即时切换，选择会自动保存在本机。

## 功能介绍

### 帕鲁图鉴

图鉴收录 300 个帕鲁条目，支持通过中文名、不完整拼音或拼音首字母、英文名、纯数字图鉴编号、技能、掉落物等信息进行搜索。

你还可以组合使用以下筛选条件：

- 帕鲁属性
- 工作适性多选；同时选择多项时，结果必须具备全部已选适性
- HP、攻击、防御、工作速度等战斗与生产数值排序
- 行走、奔跑、游泳、骑乘冲刺、搬运速度及耐力等移动数值排序
- 默认按图鉴编号升序展示，也可切换为降序；没有图鉴编号的条目始终排在有效编号之后

打开帕鲁详情后，可以继续查看：

- 中英文名称、图鉴编号、属性与五星稀有度
- 伙伴技能、主动技能和固有词条；没有固有词条时不显示空区块
- 工作适性与详细能力数值
- 掉落物品、数量与概率

宽屏下详情左栏和主动技能栏可以分别滚动；低高度或窄屏下改为弹窗内部统一滚动，背景页面始终保持锁定。

### 配种查询

配种工具提供两种常用查询方式：

- **双亲查子代**：只选择任一亲本时，按另一亲本或子代的名称、拼音、英文名、图鉴编号和内部 ID 浏览筛选全部相关配方；选择两只帕鲁后直接查看精确组合结果。
- **获取目标帕鲁**：选择想要获得的帕鲁，浏览、搜索全部可用亲本组合，并可标记或取消标记配方。

配种查询适合用来快速验证组合、寻找替代亲本，或在捕捉和培养前比较不同方案。

### 帕鲁配种图

原自动路径规划和具名已有帕鲁预设已退场，第三个配种入口已更换为“帕鲁配种图”。配种图占满应用顶栏以下的可用窗口；可伸缩“加入帕鲁”侧栏提供全部帕鲁的搜索、拖放和按钮添加，同一帕鲁可重复创建节点。双亲查询和“获取目标帕鲁”中的配方可在当前应用会话内标记，并集中显示在配种图右侧栏；标记不会改动方案，刷新后清空。

画布按亲本在上、子代在下展示无性别有向无环森林，右侧栏可切换已标记配方和当前方案的等价文本关系。节点使用由关系结构确定的固定槽位，不再自由拖动；轻量 HTML/SVG 视口仅渲染可见区域，缩放范围为 `0.2–1.5`。主题化图标工具栏包含确定性自动整理、合并、删除、查询获取方式、撤销/重做、缩放和适应画布等工具。节点、关系、位置和视口自动保存到本机 IndexedDB；当前方案还可通过 `.paltools-plan.json` 独立导入导出，导入不会覆盖现有方案。

## 适合这些场景

- 想快速比较多只帕鲁的工作能力或战斗数值
- 忘记某只帕鲁的技能、掉落物或工作适性
- 已经有两只帕鲁，想确认它们能配出什么
- 想获得特定帕鲁，需要查找可用的亲本组合
- 希望整理、保存或交换多个可编辑配种图方案
- 在无网络或网络不稳定的环境中查询常用资料

## 使用说明

PalTools 的主要功能分为“图鉴”“配种”和“设置”三个页面。

- 在“图鉴”中搜索和筛选帕鲁，点击卡片查看完整详情。
- 在“配种”中选择“双亲查子代”“获取目标帕鲁”，或进入“帕鲁配种图”编辑方案。
- 在“设置”中选择森林夜色、珍珠白、石墨灰、晴空浅蓝、薰衣草霓虹、珊瑚莓果或深海薄荷主题。

主题选择使用独立的版本化本机存储，刷新或重新启动后继续生效；无效或来自未来版本的主题配置会安全回退到默认“森林夜色”。

## 命令行工具

PalTools 附带独立 CLI 模块，供脚本和终端查询同一套离线图鉴与配种数据：

```powershell
npm run cli -- info
npm run cli -- search 皮皮鸡
npm run cli -- forward --parents SheepBall,PinkCat --json
npm run cli -- reverse --target ChickenPal --json
npm run cli -- plan validate plan.json
```

CLI 支持 `info`、`search`、`forward --parents A,B`、`reverse --target C`、`plan validate <文件>`，全局参数 `--json`、`--data-dir` 和环境变量 `PALTOOLS_DATA_DIR`；退出码 0 成功、1 校验/内部失败、2 参数或身份歧义、3 无结果、4 数据缺失或 Schema 不兼容。身份解析支持内部 ID、paldb ID、图鉴编号（含前导零）、中英文名和拼音。

构建单文件发行版：

```powershell
npm run cli:build
node build/cli/paltools.mjs --version
```

Windows 可调用 `script\paltools.cmd`；macOS/Linux 直接运行同一 `build/cli/paltools.mjs`。CLI 与 Web/Electron 共用 `src/domain` 领域逻辑和 Schema v4 数据，不发起运行时网络请求。

## 使用边界

PalTools 专注于资料查询与配种路线辅助，目前不会：

- 读取、修改或管理游戏存档
- 计算被动技能继承概率
- 统计个体数量或管理养殖库存
- 计算蛋糕、孵化时间等养殖成本
- 提供账号系统、云同步或运行时遥测

配种结果按无性别配种规则展示。游戏版本更新可能导致资料或配方发生变化，实际结果请以当前游戏版本为准。
