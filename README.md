# PalTools

PalTools 是一款面向《幻兽帕鲁》玩家的本地图鉴与配种辅助工具，帮助玩家更快查找帕鲁资料、验证配种结果，并逐步整理自己的配种方案。

工具面向桌面浏览器与 Windows 桌面版，可离线使用，不需要登录账号，也不会读取或修改游戏存档。移动设备访问时会直接显示平台不支持提示。

## 下载与运行

Windows 用户可从 [GitHub Releases](https://github.com/anApalpitate/PalTools/releases) 下载 `PalTools-0.1.0-win-x64.exe`。这是免安装便携版，下载后可直接运行；首次启动若出现 Windows 安全提示，请先核对下载来源和版本信息。

## 主要用途

- **查资料**：集中查看帕鲁的属性、工作适性、技能、掉落物和各项能力数值。
- **选帕鲁**：按名称、编号、属性和工作适性筛选，再按图鉴编号或能力数值升序、降序排列，快速找到符合需求的帕鲁。
- **查配种结果**：选择一只亲本可浏览并筛选它参与的全部配方；选择两只亲本可直接查看精确配种结果。配方可按编号或三只帕鲁的平均稀有度正序/倒序排列，并可排除传说帕鲁或同种亲本配方。
- **获取目标帕鲁**：指定目标子代，查看所有可用的亲本组合，同样支持两个头像过滤器和配方排序。
- **整理配种方案**：把任意精确配方收藏到配方背包，按多个独立方案生成文本步骤、关系列表和自动布局图形网。
- **切换界面主题**：在七套固定主题之间即时切换，选择会自动保存在本机。

## 功能介绍

### 帕鲁图鉴

图鉴收录 300 个帕鲁条目，支持通过中文名、不完整拼音或拼音首字母、英文名、纯数字图鉴编号、技能、掉落物等信息进行搜索。

你还可以组合使用以下筛选条件：

- 帕鲁属性
- 工作适性多选；同时选择多项时，结果必须具备全部已选适性
- HP、攻击、防御、工作速度等战斗与生产数值排序
- 行走、奔跑、游泳、骑乘冲刺、搬运速度及耐力等移动数值排序
- 默认按图鉴编号升序展示，也可切换为降序；没有图鉴编号的条目始终排在有效编号之后

打开帕鲁详情后，可以继续查看：

- 中英文名称、图鉴编号、属性与五星稀有度
- 伙伴技能、主动技能和固有词条；没有固有词条时不显示空区块
- 工作适性与详细能力数值
- 掉落物品、数量与概率

宽屏下详情左栏和主动技能栏可以分别滚动；低高度或窄屏下改为弹窗内部统一滚动，背景页面始终保持锁定。

### 配种查询

配种工具提供三种互通的使用方式：

- **双亲查子代**：只选择任一亲本时，按另一亲本或子代的名称、拼音、英文名、图鉴编号和内部 ID 浏览筛选全部相关配方；选择两只帕鲁后直接查看精确组合结果。
- **获取目标帕鲁**：选择想要获得的帕鲁，浏览、搜索全部可用亲本组合。
- **配种方案网**：从任一查询结果收藏配方，在持久化配方背包中搜索、过滤和批量选择，再加入默认方案或最多 20 个自定义方案。方案必须保持无环；自交、直接自循环和失效关系仍可留在背包中查看、导出或移除，但不能加入方案。

两种查询的配方卡会用五星图形展示亲本 A、亲本 B 和子代的稀有度。当前配种索引中只能通过自身与自身配种得到自身的帕鲁视为传说帕鲁，以金色边框和菱形标记显示；查询工具栏使用空涡龙头像切换“排除传说帕鲁”，使用捣蛋猫头像切换“排除同种配种”，启用后以主题危险色斜杠标记。平均稀有度排序按三个配方槽位的已知稀有度平均值排列，`▲` 为正序、`▼` 为倒序。

方案页提供等价的步骤列表、只读图形网和关系列表。配方背包、步骤和关系列表都用紧凑头像展示两个亲本与子代。图形网只把帕鲁（或实例/汇合点）作为节点，节点内显示帕鲁头像；两个亲本在图形网中完全等价，配方编号和唯一移除入口显示在规范化后的亲本关系边上，不再占用独立节点。图形网可切换合并/实例节点模式，布局在后台 Worker 中计算；大型方案默认聚焦一个稳定目标。完整工作区可导出为 JSON，并经预览和校验后整包导入。配方背包、方案及视图偏好保存在本机 IndexedDB，不上传到网络。

## 适合这些场景

- 想快速比较多只帕鲁的工作能力或战斗数值
- 忘记某只帕鲁的技能、掉落物或工作适性
- 已经有两只帕鲁，想确认它们能配出什么
- 想获得特定帕鲁，需要查找可用的亲本组合
- 在无网络或网络不稳定的环境中查询常用资料

## 使用说明

PalTools 的主要功能分为“图鉴”“配种”和“设置”三个页面。

- 在“图鉴”中搜索和筛选帕鲁，点击卡片查看完整详情。
- 在“配种”中选择“双亲查子代”或“获取目标帕鲁”。
- 在查询卡片右上角点击 `＋` 加入配方背包；图标变为 `✓` 表示已经加入，再进入“配种方案网”整理默认或自定义方案。
- 在“设置”中选择森林夜色、珍珠白、石墨灰、晴空浅蓝、薰衣草霓虹、珊瑚莓果或深海薄荷主题。

主题选择使用独立的版本化本机存储，刷新或重新启动后继续生效；无效或来自未来版本的主题配置会安全回退到默认“森林夜色”。
界面面板、文字、控件状态、警告/危险反馈、稀有度标记及配种图形网均使用对应主题的语义色板。

## 命令行工具

PalTools 附带独立 CLI 模块，供脚本和终端查询同一套离线图鉴与配种数据：

```powershell
npm run cli -- info
npm run cli -- search 皮皮鸡
npm run cli -- forward --parents SheepBall,PinkCat --json
npm run cli -- reverse --target ChickenPal --json
```

CLI 支持 `info`、`search`、`forward --parents A,B` 和 `reverse --target C`，全局参数 `--json`、`--data-dir` 和环境变量 `PALTOOLS_DATA_DIR`；退出码 0 成功、1 内部失败、2 参数或身份歧义、3 无结果、4 数据缺失或 Schema 不兼容。身份解析支持内部 ID、paldb ID、图鉴编号（含前导零）、中英文名和拼音。

构建单文件发行版：

```powershell
npm run cli:build
node build/cli/paltools.mjs --version
```

Windows 可调用 `script\paltools.cmd`；macOS/Linux 直接运行同一 `build/cli/paltools.mjs`。CLI 与 Web/Electron 共用 `src/domain` 领域逻辑和 Schema v4 数据，不发起运行时网络请求。

## 使用边界

PalTools 专注于资料查询与配种路线辅助，目前不会：

- 为手机或平板提供可操作界面
- 读取、修改或管理游戏存档
- 计算被动技能继承概率
- 统计个体数量或管理养殖库存
- 计算蛋糕、孵化时间等养殖成本
- 提供账号系统、云同步或运行时遥测

配种结果按无性别配种规则展示。游戏版本更新可能导致资料或配方发生变化，实际结果请以当前游戏版本为准。
