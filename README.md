# PalTools

PalTools 是一款面向《幻兽帕鲁》玩家的本地图鉴与配种辅助工具，帮助玩家更快查找帕鲁资料、验证配种结果，并根据自己已有的帕鲁规划获得目标帕鲁的路线。

工具可离线使用，不需要登录账号，也不会读取或修改游戏存档。

## 下载与运行

Windows 用户可从 [GitHub Releases](https://github.com/anApalpitate/PalTools/releases) 下载 `PalTools-0.1.0-win-x64.exe`。这是免安装便携版，下载后可直接运行；首次启动若出现 Windows 安全提示，请先核对下载来源和版本信息。

## 主要用途

- **查资料**：集中查看帕鲁的属性、工作适性、技能、掉落物和各项能力数值。
- **选帕鲁**：按名称、编号、属性和工作适性筛选，再按能力数值升序或降序排列，快速找到符合需求的帕鲁。
- **查配种结果**：选择两只亲本，查看它们能够配种获得的子代。
- **反查亲本组合**：指定目标子代，查看所有可用的亲本组合。
- **规划配种路线**：以自己已拥有的帕鲁为起点，寻找获得目标帕鲁所需的配种路径。

## 功能介绍

### 帕鲁图鉴

图鉴收录 300 个帕鲁条目，支持通过中文名、英文名、图鉴编号、技能、掉落物等信息进行搜索。

你还可以组合使用以下筛选条件：

- 帕鲁属性
- 工作适性多选；同时选择多项时，结果必须具备全部已选适性
- HP、攻击、防御、工作速度等战斗与生产数值排序
- 行走、奔跑、游泳、骑乘冲刺、搬运速度及耐力等移动数值排序

打开帕鲁详情后，可以继续查看：

- 中英文名称、图鉴编号、属性与稀有度
- 伙伴技能、主动技能和固有被动技能
- 工作适性与详细能力数值
- 掉落物品、数量与概率

### 配种查询

配种工具提供两种常用查询方式：

- **双亲查子代**：选择两只帕鲁，直接查看配种结果。
- **子代反查亲本**：选择想要获得的帕鲁，浏览并搜索全部可用亲本组合。

配种查询适合用来快速验证组合、寻找替代亲本，或在捕捉和培养前比较不同方案。

### 配种路径规划

当目标帕鲁无法通过现有亲本一步获得时，可以使用路径规划功能：

1. 将已有帕鲁加入“已拥有”列表，或添加仅在当前使用期间有效的临时起点。
2. 选择目标帕鲁。
3. 使用“最少代数”寻找较短路线，或指定希望规划的代数。
4. 在配种树和文本步骤中查看每一代所需的亲本与子代。

配种树中的中间节点还可以切换为其他可用配方，便于根据实际拥有的帕鲁调整路线。“已拥有”列表支持圆形头像标签；添加或删除后需要点击“保存到本机”才会持久化，未保存时离开路径页会收到提醒。

## 适合这些场景

- 想快速比较多只帕鲁的工作能力或战斗数值
- 忘记某只帕鲁的技能、掉落物或工作适性
- 已经有两只帕鲁，想确认它们能配出什么
- 想获得特定帕鲁，需要查找可用的亲本组合
- 希望利用现有帕鲁逐代配出目标，并清楚看到完整步骤
- 在无网络或网络不稳定的环境中查询常用资料

## 使用说明

PalTools 的主要功能分为“图鉴”“配种”和“管理员配置”三个页面。

- 在“图鉴”中搜索和筛选帕鲁，点击卡片查看完整详情。
- 在“配种”中选择正向查询、反向查询或路径规划。
- 在“管理员配置”中调整指定代数配种树的展示上限；该设置只影响本机。

## 使用边界

PalTools 专注于资料查询与配种路线辅助，目前不会：

- 读取、修改或管理游戏存档
- 计算被动技能继承概率
- 统计个体数量或管理养殖库存
- 计算蛋糕、孵化时间等养殖成本
- 提供账号系统、云同步或运行时遥测

配种结果按无性别配种规则展示。游戏版本更新可能导致资料或配方发生变化，实际结果请以当前游戏版本为准。
