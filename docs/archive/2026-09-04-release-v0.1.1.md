# PalTools v0.1.1

PalTools v0.1.1 是一次 Windows x64 便携版更新，汇总 v0.1.0 之后的图鉴、配种方案网、主题、离线 CLI 与桌面打包改进。

## 主要更新

- 新增持久化配方背包与自动配种方案网，支持步骤列表、关系列表、只读图形网、多方案管理及工作区导入导出。
- 完善双亲查询与目标反查的搜索、稀有度排序、传说/自交过滤，以及配种头像到图鉴详情的连续导航。
- 优化图鉴筛选、工作适性排序、详情信息密度与滚动反馈，并修复低高度视口下的详情浏览体验。
- 提供七套主题并统一界面语义色、控件状态和图形网配色。
- 新增离线 CLI，支持帕鲁搜索、资料查询、正向配种与反向配种命令。
- 配方背包过滤工具栏改为一行五格主题化图标按钮，Windows 便携包同时缩减无关运行时资源。

## 验证

- Vitest：22 个测试文件、216 项测试全部通过。
- 数据校验：300 个帕鲁、44,851 条无性别配方、44,850 个亲本组合、307 个主动技能、116 个掉落物条目和 115 个掉落物图标通过。
- TypeScript 全量检查与 Vite 生产构建通过；保留既有的大 chunk 提示。
- Windows 已打包应用通过 Schema、反向索引、主动技能、掉落物图标、主题设置和配种工作区 smoke。
