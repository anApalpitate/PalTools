# 第二阶段：图鉴增强

第二阶段建立了第三阶段继续使用的数据基础。

## 已交付

- 10 个稳定属性 ID；9 个 paldb 来源 WebP 和 1 个项目未知占位。
- 伙伴技能名称与完整说明。
- HP、攻击、防御、工作速度、行走、奔跑、游泳、耐力、进食量。
- PalCalc 补充骑乘冲刺与搬运参数，所有非空数值记录来源。
- 图鉴全文搜索、单项包含边界的数值区间筛选。
- 本地属性徽标、图鉴详情分组、配种三方图片公式。
- `client/parser/media/schema/sync` 模块化爬虫，以及 `--offline` 缓存重解析。

## 空值语义

- `null`：没有可验证的直接来源。
- 空数组：来源页面已成功解析，但明确没有该类内容。
- 负数游戏哨兵值：规范化为 `null`。
- 骑乘冲刺速度只是游戏参数，不代表该帕鲁一定可骑乘。

## 与 Schema v3 的关系

第三阶段保留全部第二阶段字段与素材，将 schema 从 2 升级到 3，并增加主动技能、固有被动、掉落和紧凑双向配种索引。第二阶段生成文件不能与第三阶段运行时代码混用；`npm run data:validate` 会拒绝旧 schema。
