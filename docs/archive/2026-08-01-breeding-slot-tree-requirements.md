# 配种图分层槽位需求摘要

## 文档定位

本文覆盖 REQ-010–013 的产品范围和验收入口。槽位、插入、fork、产生子代、递归删除、布局和事务规则统一引用 [`2026-08-01-layered-slot-graph-logic.md`](2026-08-01-layered-slot-graph-logic.md)，不在此重复定义。

## 需求范围

- REQ-010：光标模式合并节点选择与空白区域平移；仅平移模式禁止选择节点；查询模式用于点击查询。
- REQ-011：提供固定 Ctrl+C、Ctrl+V、Ctrl++、Ctrl+-、Ctrl+滚轮快捷键；不提供 Ctrl+T/剪切，也不支持用户配置。
- REQ-012：加入帕鲁和右侧配方/关系列表使用左右图标入口，桌面占用安全区域，窄屏使用互斥覆盖面板。
- REQ-013：使用“按代数分行、按行内顺序排列”的槽位图，不使用自由画布坐标作为结构真相。

## 必须保留的产品行为

- 空方案显示一个空槽位；非空方案通过合法插入槽位扩展行内顺序。
- 已产生关系的亲本必须保持相邻，亲本间隙不可插入。
- 产生子代时必要的对齐通过 fork 完成；fork 是真实节点，保留 `forkOf` 来源。
- 删除节点递归删除其所有后代和受影响关系；删除确认和退出动画以红色显示整个受影响区域。
- 从加入列表拖放时，合法空槽位提供脉冲、发光和占位反馈；取消、失焦、离开编辑器和失败后清除临时状态。
- v1 不迁移。数据库升级清除旧方案数据并创建空白 v2 方案；v1 导入文件拒绝且不覆盖 v2 数据。

## 验收入口

实现应覆盖空图创建、左右插入、已有关系保护、同层相邻/非相邻和跨层产生子代、无空位时 fork、后代闭包删除、快捷键、左右面板、动态拖放反馈、响应式溢出和 v2 持久化。详细测试与交付门见专项逻辑文档第 11 节。
