# PalTools v0.1.0

PalTools v0.1.0 是首个 Windows 便携版发布，集中完成图鉴详情、筛选排序、配种选择器、路径规划和本机保存体验的修复。

## 主要更新

- 图鉴详情锁定背景页面；桌面常用尺寸仅主动技能区滚动，低高度和窄屏使用弹窗内部滚动回退。
- 提升属性、伙伴技能、数值、工作适性和主动技能信息的文字可读性。
- 配种相关帕鲁选择器支持滚轮、键盘和长列表滚动；再次打开时显示全部候选、定位当前项并全选已有文字。
- 工作适性补充 12 种离线图标，改为 AND 多选，并移除“适性最低等级”。
- 图鉴数值范围过滤改为升序/降序排列，支持和搜索、属性及工作适性过滤组合使用。
- 已拥有帕鲁改为圆形头像标签；新增和删除仅在点击“保存到本机”后持久化，并提供未保存离开提醒。
- 最少代数模式隐藏指定代数输入框，指定 N 代模式保留最近一次合法值。
- 应用内滚动条统一为 PalTools 深色绿色主题。

## 验证

- 7 个测试文件、30 个自动化用例全部通过。
- TypeScript 全量检查、数据完整性校验和 Web 生产构建通过。
- Playwright 覆盖 1920×1080、1536×864、1366×768 和 390×844。
- 正向配种、子代反查、路径规划、管理员配置和本地存储回归通过。
- Windows 便携 EXE 通过 Schema v4、反向索引、主动技能、掉落图标和默认配置上限冒烟。
