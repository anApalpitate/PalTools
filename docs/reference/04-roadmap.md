# 实施路线图

## 阶段 0：环境与需求（已完成）

React、TypeScript、Vite、Vitest、离线静态数据和基础文档。

## 阶段 1：图鉴与完整配种矩阵（已完成）

299 个 paldb 页面、本地帕鲁图、44,851 条固定正式版配方、双亲查询与 Electron 一键打包。

## 阶段 2：图鉴详细数值与展示（已完成）

本地属性图标、伙伴技能说明、详细战斗/生产/移动数值、数值筛选、图形配种公式和模块化离线爬虫。

## 阶段 3：反向配种、路径规划与内容增强（已完成）

- Schema v4 紧凑正反向索引、工作适应性素材与无性别公式。
- 目标子代反查、分页和全结果搜索。
- “已拥有”与“临时起点”、最少代数和精确 1–12 代算法。
- 默认六代、管理员可配置上限、超限只报告准确代数。
- React Flow 路径树、文本步骤与节点替代配方。
- 主动技能、固有被动、掉落物和本地图标。

退出条件：数据、领域、组件、真实浏览器、离线构建和 EXE 冒烟全部通过。

## 阶段 4：配种工作流重构（进行中）

已确认以可编辑配种图完全替换自动路径规划，详细范围见 [02-breeding-graph-requirements.md](../tasks/02-breeding-graph-requirements.md)：

1. 建立独立的已有帕鲁预设，并支持创建、切换、重命名、删除和显式保存。
2. 预设与配种图方案采用多对多关系，二者可以独立切换和删除。
3. 将“子代反查亲本”改为“获取目标帕鲁”，支持把配方追加到当前方案。
4. 实现亲本在上、子代在下的可编辑无性别配种森林，以及节点合并、工具栏和文本关系列表。
5. 支持方案 JSON 导入导出，并迁移旧版已有帕鲁集合。

阶段 1 基础建设已于 2026-07-30 完成：旧自动路径工具、Worker 和代数设置已移除；第三入口替换为配种图空状态；图领域 Schema、约束校验、IndexedDB v1 仓储及旧已有帕鲁一次性迁移已落地。

阶段 2 资源管理已于 2026-08-01 完成：预设选择和显式保存、方案增删改查、独立切换、多对多关联入口、全局未保存保护及失败恢复已经落地。下一步建立可持久化配种森林核心。

2026-07-31 补齐双亲查询的单亲浏览能力：只选择任一亲本即可查看、搜索和分页浏览该帕鲁参与的全部配方；完整配方后续追加到配种图的入口仍归阶段 4 实施。

其后候选：栖息地、掉落来源反查、主动技能反查、只读存档导入、被动继承规划。历史分析见 [archive/03-next-phase-recommendations.md](../archive/03-next-phase-recommendations.md)，当前问题与需求以 [01-future-feature-requirements.md](../tasks/01-future-feature-requirements.md) 为准。

## 长期不做

存档修改、账号系统、云同步、广告、默认遥测和未经确认的素材公开再分发。
