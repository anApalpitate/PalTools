# 产品需求

## 1. 产品目标

PalTools 是《幻兽帕鲁》的离线辅助工具。它把图鉴、正向配种查询和目标子代反查集中到一个简单的本地界面中。核心查询不能依赖运行时网络，桌面包不得读取或修改游戏文件。

## 2. 当前数据范围

- 图鉴来源并集 300 条：299 个 paldb 公开详情页，加 1 个仅由固定 PalCalc 数据补充的条目。
- 44,851 条无性别公式，覆盖 44,850 个允许同种亲本的无序组合。
- Katress + Wixen 是唯一双结果组合，返回 Katress Ignis 与 Wixen Noct。
- 307 个去重主动技能、2,380 条技能解锁引用、51 条页面固有被动、1,643 条掉落记录。
- 116 个掉落物目录条目、115 个唯一图标文件；来源共用同一图标时不重复存储。

## 3. 图鉴需求

- 按中文名、无声调连续拼音及首字母、英文名、内部 ID、图鉴号搜索；全文搜索伙伴技能、主动技能、固有被动、掉落物名称和说明。
- 按属性、工作适性及详细数值筛选、排序；缺失值不匹配数值范围。
- 详情展示身份、伙伴技能、属性、工作适性、数值、固有词条、掉落和主动技能；无固有词条时隐藏空区块。
- 桌面低宽度视口下改为纵向布局，所有字段保持直接可见；移动设备不进入应用功能界面。
- 所有图片从本地读取，损坏时使用项目占位。

## 4. 配种查询

### 双亲查子代

- 只选择亲本 A 或 B 时，两个位置语义等价，列出该帕鲁参与的全部无性别配方。
- 单亲结果按另一亲本图鉴号、子代图鉴号和内部 ID 稳定排序，每页 50 条，并显示匹配数与总数。
- 单亲结果可按另一亲本或子代身份筛选；更换或清空亲本时清除旧筛选。
- 选择两只亲本后显示本地图片和完整公式；交换只改变展示顺序。
- Katress 与 Wixen 同时显示两个无性别结果。
- 单亲和精确双亲结果可通过点击排序按钮在身份编号与三个配方槽位的平均稀有度间切换；独立方向图标默认 `▲` 正序，点击切换为 `▼` 倒序，缺失稀有度始终排在已知值之后。查询过滤图标提供可访问名称与悬停说明。

### 获取目标帕鲁

- 选择目标子代，列出全部亲本组合。
- 按亲本图鉴号和名称稳定排序。
- 在完整结果集内按中英文名、编号和内部 ID 搜索，每页 50 条。
- 结果可按身份编号或三个配方槽位的平均稀有度排序，并使用同样的 `▲` 正序/`▼` 倒序切换；缺失稀有度始终排在已知值之后。

### 查询卡与传说帕鲁

- 当前配种索引中，某帕鲁的全部子代配方都仅为“自身 + 自身 → 自身”时，将其派生为传说帕鲁；判定不依赖手工名单。
- 两种查询均以空涡龙头像提供“排除传说帕鲁”，并以捣蛋猫头像提供“排除同种配种”，默认均关闭；启用项覆盖主题危险色斜杠。前者过滤任一槽位包含传说帕鲁的配方，后者仅过滤两个亲本 ID 相同的配方；两个过滤器可组合，正反向查询各自保存会话状态。
- 配方卡以五星图形分别展示亲本 A、亲本 B 和子代的稀有度；传说帕鲁使用当前主题的金色警示令牌绘制边框、光晕和菱形标记，并保留可访问名称。
- 查询卡右上角以小型 `＋` 图标加入配方背包，加入后显示不可重复提交的 `✓`；收藏、过滤和排序方向图标均提供简短悬停说明及中文可访问名称。

### 配种方案网

- 三个配种入口使用真实标签页语义和完整键盘导航；所有正向、单亲与反向查询卡片都可按 `recipeIndex` 幂等加入配方背包。
- 配方背包持久保存精确配方快照，可按亲本或子代身份搜索，组合使用图标形式的“过滤已加入项”和“排除自交”，并通过“按加入时间排序”按钮在加入时间与配方编号间稳定排序；实心三角方向图标切换正倒序，右侧提供当前结果的全选/取消全选。背包项以放大的头像与紧凑行高展示两个亲本与子代，并提供单条加入/移出操作；批量加入与批量移除操作使用主题的强调色与危险色。空背包提供同色的双亲查询与目标反查入口。
- 默认方案固定存在，另可创建最多 20 个自定义方案。方案关系彼此独立；默认方案不可重命名或删除，清空和删除均需确认。
- 配方背包允许任意精确配方，包括自交和直接自循环；失效或会成环的关系仍可查看、导出和移出，但不能加入方案。单条与批量加入都保持方案为 DAG，批量循环冲突整批拒绝。
- 方案以同一派生结果提供文本步骤、关系列表和只读图形网。图形网固定按“亲本在上、子代在下”阅读，将两个亲本规范化为无序集合，并以每条配方一个非卡片式的小型汇合点表达“三元关系”：普通配方的两条亲本输入边汇合后，由唯一子代输出边连接子代；同种亲本只生成一条带 `×2` 的输入边。配方编号与唯一移除入口只显示在子代输出边上。单条关系始终自动使用简洁合并图；多关系方案仍支持合并/实例节点模式、目标定位、适应视图和大型方案目标聚焦。交换快照中的亲本 A/B 不改变图输入或布局，但不影响查询顺序、步骤文本和持久化身份。文本步骤始终保留全部有效分量和失效关系警告。
- 完整工作区可导出 JSON，并经结构、引用、方案数量和循环校验后预览、确认、单事务导入。数据版本不同允许导入，关系会按当前配方索引重新判定有效性。
- 手工配种图仍为已退场功能；应用只删除旧 `paltools-breeding` IndexedDB，不迁移旧方案，也不误删当前 `paltools-breeding-network` 工作区。

## 5. 本机设置

- 设置页当前包含七套固定界面主题，森林夜色为默认值。
- 主题选择即时应用并保存到 paltools.theme.v1；缺失、损坏或未知主题回退到森林夜色。
- 主题卡片使用单选语义、可见选中标记及方向键导航，并遵守减少动效偏好。
- 所有业务组件及 React Flow 图形网必须消费当前主题的语义颜色令牌；警告、危险、稀有度和选中状态保留含义，不得回退到固定主题色或第三方默认色。
- 旧代数配置字段停止读取，但至少保留一个发布周期。

## 6. 非功能验收

- 正反向常规查询目标低于 100ms。
- 500 条关系 fixture 下，领域筛选、排序和单条操作目标低于 300ms；大型方案默认聚焦目标闭包，派生与 Worker 布局目标低于 1 秒。
- 断网时图鉴、技能、掉落、正反向查询、关系收藏和方案编辑均可用，运行时不访问第三方服务。
- 桌面浏览器与 Windows 桌面版为唯一支持的平台；检测到手机、平板或移动 UA 时直接显示“不支持移动端”画面，不渲染应用壳和功能页。窄宽度的桌面 UA 仍可使用。
- 1440×900、1152×720、1366×768 等常见桌面视口可用，主要控件支持键盘操作且不得产生意外横向滚动。
- 主题正文文字对比度至少 4.5:1，焦点、控件边界和选中状态至少 3:1。
- 每套主题必须完整定义结构、文字、强调、警告、危险和稀有度令牌；主题预览色必须来自对应主题令牌。
- 普通代码交付需通过测试、类型检查、数据校验和生产构建；正式桌面发布还需通过便携包 smoke。

## 7. 边界

不处理个体数量、孵化时间、蛋糕成本、被动继承概率、存档导入或修改、账号、云同步或运行时遥测。
