# 产品需求

## 1. 产品目标

PalTools 是《幻兽帕鲁》的离线辅助工具。它把图鉴、正反向配种查询和分阶段建设的可编辑配种图集中到一个简单的本地界面中。核心查询不能依赖运行时网络，桌面包不得读取或修改游戏文件。

## 2. 当前数据范围

- 图鉴来源并集 300 条：299 个 paldb 公开详情页，加 1 个仅由固定 PalCalc 数据补充的条目。
- 44,851 条无性别公式，覆盖 44,850 个允许同种亲本的无序组合。
- `Katress + Wixen` 是唯一双结果组合，返回 `Katress Ignis` 与 `Wixen Noct`。
- 307 个去重主动技能、2,380 条技能解锁引用、51 条页面固有被动、1,643 条掉落记录。
- 116 个掉落物目录条目、115 个唯一图标文件；来源共用同一图标时不重复存储。

## 3. 图鉴需求

### 浏览和检索

- 按中文名、无声调连续拼音及首字母、英文名、内部 ID、图鉴号搜索；拼音支持大小写不敏感的连续片段，纯数字可忽略图鉴号前导零。
- 全文搜索伙伴技能、主动技能、固有被动以及掉落物名称和说明。
- 按属性、工作适性及最低等级筛选。
- 选择单项详细数值，并使用包含边界的最小/最大值筛选；缺失值不匹配。

### 详情

- 桌面端左侧展示身份、伙伴技能、属性、工作适性、数值、固有词条和掉落；无固有词条时隐藏整个区块。
- 稀有度以 5 颗星展示：1–5 级使用黄色实心星，6–10 级依次覆盖为彩色渐变星；高于 10 的现有条目饱和显示为 5 颗彩色星并保留原始无障碍文本。
- 右侧单列展示主动技能完整卡片：名称、属性、攻击类型、解锁等级、威力、冷却、状态效果、攻击范围和说明。
- 768px 宽度下改为纵向布局，所有字段保持直接可见。
- 页面没有直接数据的合并条目显示“暂无直接来源数据”，不得从基础形态猜测。
- 所有图片从本地读取；损坏时使用项目占位，不导致页面崩溃。

## 4. 配种需求

### 双亲查子代

- 只选择亲本 A 或 B 时，两个位置语义等价，列出该帕鲁参与的全部无性别配方。
- 单亲结果按另一亲本图鉴号、子代图鉴号和内部 ID 稳定排序，每页 50 条，并显示匹配数与总数。
- 单亲结果可按另一亲本或子代的中文名、连续拼音/首字母、英文名、图鉴号和内部 ID 筛选；更换或清空亲本时清除旧筛选。
- 选择亲本 A、B，显示本地图片和完整 `A + B → C` 公式。
- 交换只改变展示顺序，不改变无序组合。
- 不显示任何亲本性别输入或提示。
- Katress 与 Wixen 同时显示两个无性别结果。

### 目标反查亲本

- 选择目标子代，列出全部亲本组合。
- 按亲本图鉴号和名称稳定排序。
- 在完整结果集内按中英文名、编号和内部 ID 搜索。
- 每页 50 条。

### 帕鲁配种图（分阶段建设）

- 自动路径规划、最少/指定代数、推荐树和节点替代配方已移除。
- 当前第三个配种入口为稳定的“帕鲁配种图”空状态；预设管理和可编辑画布尚未开放。
- 已定义预设、方案、多对多关联、节点、配种关系、视口和导出文件 Schema。
- 图关系要求节点 ID 唯一、每个子代最多一条生成关系、引用完整、配方一致且整体为有向无环结构。
- 预设、方案和关联使用 `paltools-breeding` IndexedDB；旧 `paltools.path-starts.v1` 仅在首次初始化时迁移为预设，原键暂不删除。
- 完整交互及后续阶段范围以 [07-breeding-graph-requirements.md](07-breeding-graph-requirements.md) 为准。

## 5. 本机设置

- 顶部提供无口令的本地“设置”页，当前包含界面主题。
- 当前固定提供森林夜色、珍珠白、石墨灰、晴空浅蓝、琥珀橙、薰衣草霓虹、珊瑚莓果和深海薄荷八套主题；森林夜色为默认值。
- 主题选择即时应用并保存到 `paltools.theme.v1`；缺失、损坏或未知主题回退到森林夜色。
- 页面在 React 首次渲染前应用已保存主题，切换动画约 150ms，并遵守 `prefers-reduced-motion`。
- 主题卡片使用单选语义、可见选中标记及方向键导航；第一版不提供跟随系统或任意自定义颜色。
- 主题令牌覆盖画布、表面、文字、边框、焦点、遮罩、阴影、滚动条、属性标签、工作适性和配种卡片外观；属性图标、稀有度及状态身份色保持稳定。
- `paltools.admin-config.v1` 的旧代数上限字段已停止读取，但至少保留一个发布周期，不主动删除。

## 6. 非功能验收

- 正反向常规查询目标低于 100ms。
- 配种图仓储初始化和旧数据迁移不得阻塞正反向查询。
- 断网时图鉴、技能、掉落和正反向查询均可用；配种图后续功能仍只使用本机数据。
- 常见桌面宽度与 768px 可用；主要控件支持键盘操作。
- 主题正文文字对比度至少 4.5:1，焦点、控件边界和选中状态至少 3:1；选中状态不只依赖颜色。
- `npm test`、`npm run typecheck`、`npm run data:validate`、`npm run build`、`npm run package:exe` 全部通过。

## 7. 边界

不处理个体数量、孵化时间、蛋糕成本、被动继承概率、存档导入/修改、账号、云同步或运行时遥测。
