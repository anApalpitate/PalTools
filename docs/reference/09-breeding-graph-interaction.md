# 配种图交互

配种图占据应用顶栏以下的剩余窗口。渲染由轻量 HTML 节点层、单一 SVG 连线层和统一变换层组成；画布只是领域结构的视图，不能把像素位置写回业务模型。

## 布局与视口

- 领域布局按 `layers[].nodeIds` 确定行与稳定顺序，并生成节点矩形、关系边和插入目标。
- 结构签名变化时重新计算布局；平移和缩放只更新变换层，不重算结构。
- 缩放范围统一钳制到 `0.2–1.5`；适应画布使用实际节点包围盒和面板安全区。
- 滚轮缩放以当前指针为锚点；`Shift + 滚轮` 横向平移；视口稳定后单独保存，不进入结构撤销、内容 dirty 或离开确认。
- 从加入面板创建节点后保持当前缩放，仅在节点不可见时做最小平移。

## 工具模式

工具栏固定提供三种指针模式：

- 光标：点击节点选择，拖动节点进入组合目标，拖动空白区域平移。
- 仅平移：任意有效画布拖动只改变视口，不改变选择或结构。
- 查询：点击节点进入目标查询流程，完成后通过页面返回上下文回到原方案。

Escape 取消当前确认或临时交互；工具模式必须同步提供可访问名称、激活状态和对应鼠标样式。

## 加入、组合与临时反馈

- 左侧“加入帕鲁”面板默认列出完整数据集，使用统一身份搜索；条目既可通过按钮加入，也可使用自定义 MIME 类型拖放。
- 空图接受第一个节点；非空图在合法左右插入槽位显示放置目标。受保护亲本间隙不能接受插入。
- 节点拖动到另一节点的组合目标后查询配方；多结果时由用户选择具体子代，取消时不留下节点或关系。
- 合法拖放、组合和删除目标使用明确的临时高亮；取消、指针离开、窗口失焦或失败后清理临时状态。临时状态不写入方案或撤销历史。
- 本地图片不参与浏览器原生拖拽；加入列表和图节点禁用不必要的文字选择。

## 选择、删除与历史

- 画布支持单选和多选节点；复制保存所选帕鲁身份，粘贴通过合法槽位创建新节点实例。
- 删除确认使用领域层计算后代闭包，节点和关联线同时显示红色预览，并报告受影响节点与关系数量。
- 确认后先提交原子删除，再显示最长 240ms 的退出快照；退出元素不再参与布局、选择、拖放或保存。
- 每个方案保留最多 100 条当前会话撤销/重做历史。结构内容进入历史，视口变化不进入历史。

## 快捷键

- `Ctrl+C`：复制当前选择。
- `Ctrl+V`：粘贴到当前合法目标或默认扩容位置。
- `Ctrl++`、`Ctrl+=`、`Ctrl+-`：缩放。
- `Ctrl+滚轮`：以指针位置缩放。
- 不实现剪切、`Ctrl+X`、`Ctrl+T` 或用户自定义快捷键。
- 文本框、下拉框和其他可编辑控件获得焦点时，不拦截其原生编辑快捷键。

## 左右面板与文本等价物

- 左侧图标控制加入面板；右侧图标控制配方/关系面板。窄屏下两侧面板互斥并覆盖画布，不改变领域层顺序。
- 右侧面板包含“已标记配方”和“当前方案关系”两个标签页。配方标记按 `recipeIndex` 在当前会话有序去重，不进入 IndexedDB 或导出文件。
- 当前方案关系提供与图形森林等价的完整文本步骤；图形画布不能成为唯一可用表达。

## 可访问性与响应式验收

- 加入按钮、工具按钮、节点、标签页和弹窗必须具备键盘路径、可访问名称、可见焦点和状态消息；拖放不是唯一操作方式。
- 删除、选中和合法目标不能只依赖颜色；`prefers-reduced-motion` 下动画降级为静态边框、覆盖和文字提示。
- 至少检查 1440×900、1152×720、1366×768 以及窄屏或低高度视口；页面、面板和滚动区不得产生意外横向溢出。
- 浏览器验收同时检查本地图片、控制台、第三方请求、实际滚动容器、键盘导航、原生图片拖拽和文字选择防护。
