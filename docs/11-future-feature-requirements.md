### BUG-004 白色主题下工作适性背景色观感不佳

白色主题下，图鉴页面“工作适性”区域的背景色与整体页面层次、边框和文字对比不够协调，影响信息识别和视觉观感。后续应重新调整该区域的背景色及相关边界样式，确保浅色背景下仍有清晰的层级、足够的对比度，并与其他主题的语义令牌保持一致。

### BUG-005 配种卡片渐变色未随主题切换

配种工具中的配种卡片使用了固定渐变色，切换颜色主题后渐变效果仍保持不变，导致卡片与当前主题的背景、强调色和整体氛围不协调。后续应将渐变起止色、叠加层和相关文字/边框颜色接入主题语义令牌，并覆盖主题切换、刷新恢复、桌面和窄屏布局的视觉回归验证。

### REQ-003 新增主题

在现有森林夜色、珍珠白、石墨灰、晴空浅蓝和琥珀橙之外，补充以下三套风格差异明显、偏热门审美方向的主题候选：

- **薰衣草霓虹**：深紫背景 `#211A3A`、薰衣草紫 `#B79CFF`、电光青 `#44E5D0`，突出科技感和高对比度。
- **珊瑚莓果**：暖白背景 `#FFF4EE`、珊瑚红 `#FF6B6B`、莓果紫 `#B83B7E`，突出明快、活泼的编辑型配色。
- **深海薄荷**：深海靛蓝 `#102A43`、薄荷绿 `#5EEAD4`、海盐青 `#A7F3D0`，突出清爽、沉浸的海洋型配色。

新增主题应完整覆盖背景、文字、边框、控件、状态、属性标签外观和图标等语义令牌；属性外观颜色不得在组件中重新硬编码。主题切换、刷新恢复、桌面/窄屏布局、键盘操作和对比度均需纳入验证。

### REQ-004 图鉴与配种关系 CLI 工具

未来提供高可用度的命令行工具，用于图鉴查询和配种关系检索。需求至少包括：

- 支持名称、拼音、图鉴编号、属性、工作适性和技能等常用查询条件；
- 支持正向配种、反向亲本查询，以及后续配种图方案和关系检索；
- 默认离线读取项目生成的数据，不依赖运行时第三方网络请求；
- 提供稳定、适合脚本处理的 JSON 输出，同时提供便于人工阅读的表格或文本输出；
- 对参数错误、无结果、数据版本和数据缺失给出明确退出码与错误信息；
- 支持 Windows，并评估 macOS、Linux 以及便携分发方式；
- CLI 与 Web/Electron 共用领域逻辑、数据 Schema 和版本信息，避免三套规则分叉。

## 已完成问题修复

### 属性外观、应用版本与默认排序文案

- `BUG-001`：属性标签、边框、表面和筛选状态改用五套主题均完整定义的属性语义令牌；火、水、雷等来源图标继续保留身份色。
- `BUG-002`：应用版本统一由 `package.json` 经 `VITE_APP_VERSION` 构建变量注入，右上角只显示应用版本；数据集版本继续由 manifest 独立维护。
- `BUG-003`：排序选项显示为“图鉴编号”，默认升序、方向切换和重置行为保持不变。

### 搜索支持不完整拼音和纯数字图鉴编号

- 中文名称会生成无声调连续拼音和拼音首字母别名，支持大小写不敏感的连续片段匹配。
- 纯数字查询可匹配去除前导零后的图鉴编号，并保留字母后缀条目的前缀匹配。
- 图鉴搜索、配种选择框和反向亲本筛选共用身份搜索规则。
- 中文名、英文名、内部 ID、技能、掉落物、属性和工作适性能力保持不变。

### 宽屏顶部栏左右过渡

- 顶部栏内容继续与 1440px 主内容区对齐，背景、模糊层和底部边界延伸到整个视口宽度。
- 常见桌面宽度、125% 缩放有效视口和窄屏布局不产生横向溢出。

### 稀有度五角星展示

- 稀有度固定使用一行 5 颗星展示；1–5 级使用黄色实心星和空心星。
- 6–10 级从左向右用彩色渐变星覆盖黄色星；现有数据中高于 10 的条目饱和显示为 5 颗彩色星，同时保留原始数值的无障碍文本。
- 缺失稀有度时继续显示“暂无数据”。

### “固有词条”命名与空状态

- 详情页将“固有被动技能”统一显示为“固有词条”。
- 数据为 `null` 或空数组时不渲染标题、空状态或空白区块。
- 有词条时继续展示名称、Rank 和描述。

### 详情弹窗左右栏独立滚动

- 桌面布局下，左侧详情与右侧主动技能支持独立上下滚动。
- 滚动一侧不会带动另一侧、整个弹窗或背景页面。
- 低高度和窄屏下回退为弹窗内部整体滚动，确保全部内容可访问。
- 滚动条按悬停、键盘聚焦和滚动状态显示，并保持内容布局稳定。

### 固有词条区域视觉错位

- 固有词条、工作适性和掉落物品区块保持稳定排列。
- 标题、卡片、Rank 和多行描述不再错位、重叠或产生异常留白。
- 无词条时隐藏区块；有一项和多项词条时布局均保持一致。

### 默认顺序支持调整排列方向

- 默认顺序按图鉴编号处理，并支持升序和降序。
- 无图鉴编号的条目在两个方向下均稳定排在有效编号之后。
- 搜索和筛选变化后保留当前排列方向，重置后恢复图鉴编号升序。

### 重置按钮视觉不够醒目

- 图鉴筛选区的重置按钮无需悬停即可识别。
- 默认、悬停、按下和键盘聚焦状态均清晰可辨。
- 桌面和窄屏下不会挤压相邻排序控件。

### 配种结果卡片重复展示子代名称

- 移除卡片底部重复的子代摘要区域。
- 正向配种和反向查询的公式布局均保持清晰。
- 子代头像、名称、角色和完整可访问文本仍然保留。

### 目标子代选择框过长

- 宽屏下目标子代选择框不再占据过多横向空间。
- 候选面板仍可展示完整名称、英文名和图鉴编号，并支持滚动与键盘选择。
- 1366×768 和窄屏下无水平溢出，控件可恢复全宽。

### 应用品牌图标

- Electron 应用和便携 EXE 使用新的关联图标。
- 顶栏使用 `public/app-icon-96.png`，favicon 使用 `public/favicon-32.png`。
- Windows 多尺寸图标位于 `script/electron/resources/icon.ico`，母版位于 `script/electron/resources/icon.png`。
- 图标来源、提示词和派生流程已记录在数据与合规文档中。
