# 临时任务文档

本目录存放进行中或最近完成的任务计划、验证记录和临时结论，不作为长期行为依据。

规则：
- 命名：`YYYY-MM-DD-<任务名>.md` 或 `<编号>-<名称>.md`。
- 只记录当前任务：目标、范围、验证结果、待办和阻塞点。
- 任务完成后：长期结论并入 `../reference/`，任务文件移入 `../archive/` 或删除。
- agent 默认只读当前任务对应文件，不把其他任务记录当作当前真相。
