## REQ-005：删除琥珀橙主题

### 目标

固定主题从八套缩减为七套，删除主题 ID `amber` 及设置页中的“琥珀橙”卡片，其他主题的配色和默认顺序保持不变。

### 实现边界

- 从主题注册表、完整语义令牌块、主题预览数据及对应测试用例中移除 `amber`。
- 已保存为 `amber` 的 `paltools.theme.v1` 偏好按未知主题处理，安全回退到默认的“森林夜色”，不得导致启动失败或空白主题。
- 更新主题数量、键盘循环选择、对比度检查、README、产品需求和 Electron smoke 断言。
- 不改变主题存储键和 `ThemePreferenceV1` Schema；不迁移为另一套非默认主题。

### 验收

- 设置页只显示七套主题，键盘方向键顺序连续。
- 首次启动、普通主题恢复和旧 `amber` 偏好回退均正确。
- 七套主题在图鉴、详情、配种查询和配种图中无缺失令牌、异常背景或对比度退化。

## REQ-006：配种图交互重构

### 1. 概念调整

取消“预设”作为具名、可持久化资源的产品概念。原预设创建、切换、重命名、删除、显式保存、未保存离开保护，以及预设—方案多对多关联全部退场。

保留的帕鲁选择能力改为“加入帕鲁”工具：

- 默认提供全部帕鲁的可搜索素材列表，不要求先选择或创建预设。
- 选择帕鲁后可拖入画布，也可通过点击、键盘或触屏替代操作在当前视口创建新节点。
- 同一帕鲁可重复加入并创建多个节点实例；加入操作不形成独立背包、收藏或持久化集合。
- 新子代节点不再提供“加入当前预设”，只保留在当前方案中；需要重复使用时可从“加入帕鲁”工具再次创建。
- 配方追加、方案增删改查、自动保存、导入导出、撤销/重做和关系校验保持不变。

### 2. 旧数据与存储退场

- 停止创建和消费 `presets`、`plan-preset-links` 及当前预设选择状态；方案、节点、关系、位置和视口继续使用 IndexedDB。
- 现有预设和关联数据至少保留一个发布周期，不主动删除，便于降级或后续迁移；界面不再展示这些资源。
- 旧 `paltools.path-starts.v1` 不再迁移为预设，也不主动删除。
- 在实现前先确认 IndexedDB v1 是否可通过停止消费完成退场；只有必须改变存储结构时才升级数据库版本。

### 3. 全窗口配种图布局

配种图进入类似 tldraw 的画布优先模式，并按 PalTools 的顶栏、主题和 Electron 窗口进行本地适配：

- 配种图页面占满应用顶栏以下的剩余视口，画布随窗口伸缩，页面本身不产生纵向或横向滚动。
- 方案选择、保存状态、导入导出等低频资源操作压缩到紧凑的画布顶栏或浮动区域，不再挤占大块固定面板。
- “加入帕鲁”作为画布侧面的可伸缩栏目：桌面端可展开/折叠，折叠后只保留明确入口；窄屏和触屏改为覆盖式抽屉，不永久压缩画布。
- 侧栏展开状态只属于界面偏好，可按现有状态边界选择会话内保存或版本化本机保存，不与方案内容混合。
- 文本关系列表保留为可折叠辅助面板，确保图形画布之外仍有等价、可访问的关系表达。
- 画布在 1440×900、1152×720、1366×768、窄屏和低高度下都应保留可用编辑区域，弹窗与浮层不得被窗口边缘裁切。

### 4. 图标工具栏

- 选择/移动、平移、创建子代、查询、合并、删除、撤销/重做、自动整理、适应画布和缩放等工具统一使用图标按钮，集中显示在画布工具栏中。
- 图标必须配套可访问名称、Tooltip、键盘焦点、激活/禁用状态；不能只依赖图形或颜色传达含义。
- 桌面端优先单行或分组浮动工具栏；窄屏允许分组折叠，但高频操作不得埋入多级菜单。
- 工具栏背景、图标、边框、悬停、按下、选中、禁用和焦点颜色使用独立语义令牌，由七套保留主题分别完整定义；业务组件不得判断主题 ID。
- 属性身份色、成功/警告/错误状态色继续保持稳定，工具激活状态同时使用形状、描边或状态标记表达。

### 5. 实施顺序与验收

1. 删除琥珀橙主题并补齐七主题基线。
2. 移除预设 UI、Hook 状态、仓储消费和方案关联入口，保留旧数据但停止迁移与展示。
3. 将全量帕鲁列表改造成职责单一的“加入帕鲁”侧栏工具。
4. 重构配种图为视口填充布局，并将资源区、文本列表和侧栏改为可折叠面板。
5. 将画布工具改为主题化图标工具栏，补齐键盘、触屏和屏幕阅读器语义。
6. 最后统一执行组件测试、完整测试、TypeScript、数据校验、生产构建和真实浏览器回归；涉及正式桌面发布时再执行一次 `package:exe`。

验收要求：

- 用户无需创建或保存预设即可向任意当前方案添加帕鲁。
- 已有方案及其节点、关系、视口、自动保存和导入导出不受预设退场影响。
- 画布占据顶栏以下绝大部分可用空间；展开/折叠侧栏时节点与视口行为稳定，无意外页面滚动。
- 所有画布工具具备图标、文字提示、键盘名称和明确状态；七套主题均具有适配配色。
- 无横向溢出、破图、控制台错误、第三方运行时请求或键盘陷阱。
