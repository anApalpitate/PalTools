# 产品需求

## 1. 产品目标

PalTools 是《幻兽帕鲁》的离线辅助工具。它把图鉴、正反向配种查询和多代路径规划集中到一个简单的本地界面中。核心查询不能依赖运行时网络，桌面包不得读取或修改游戏文件。

## 2. 当前数据范围

- 图鉴来源并集 300 条：299 个 paldb 公开详情页，加 1 个仅由固定 PalCalc 数据补充的条目。
- 44,851 条无性别公式，覆盖 44,850 个允许同种亲本的无序组合。
- `Katress + Wixen` 是唯一双结果组合，返回 `Katress Ignis` 与 `Wixen Noct`。
- 307 个去重主动技能、2,380 条技能解锁引用、51 条页面固有被动、1,643 条掉落记录。
- 116 个掉落物目录条目、115 个唯一图标文件；来源共用同一图标时不重复存储。

## 3. 图鉴需求

### 浏览和检索

- 按中文名、英文名、内部 ID、图鉴号搜索。
- 全文搜索伙伴技能、主动技能、固有被动以及掉落物名称和说明。
- 按属性、工作适性及最低等级筛选。
- 选择单项详细数值，并使用包含边界的最小/最大值筛选；缺失值不匹配。

### 详情

- 桌面端左侧展示身份、伙伴技能、属性、工作适性、数值、固有被动和掉落。
- 右侧单列展示主动技能完整卡片：名称、属性、攻击类型、解锁等级、威力、冷却、状态效果、攻击范围和说明。
- 768px 宽度下改为纵向布局，所有字段保持直接可见。
- 页面没有直接数据的合并条目显示“暂无直接来源数据”，不得从基础形态猜测。
- 所有图片从本地读取；损坏时使用项目占位，不导致页面崩溃。

## 4. 配种需求

### 双亲查子代

- 选择亲本 A、B，显示本地图片和完整 `A + B → C` 公式。
- 交换只改变展示顺序，不改变无序组合。
- 不显示任何亲本性别输入或提示。
- Katress 与 Wixen 同时显示两个无性别结果。

### 目标反查亲本

- 选择目标子代，列出全部亲本组合。
- 按亲本图鉴号和名称稳定排序。
- 在完整结果集内按中英文名、编号和内部 ID 搜索。
- 每页 50 条。

### 路径规划

- “已拥有”保存到 `paltools.path-starts.v1`；“临时起点”只保留到当前应用会话结束。
- 两套集合只记录种类，同一种帕鲁可在配方和多个树分支中重复使用。
- 起点为第 0 代；子代代数为 `max(A 代数, B 代数) + 1`。
- 最少代数模式返回确定性推荐树；指定 N 代要求根节点恰好处于第 N 代。
- 同一根到叶路径不得重复同一帕鲁，避免循环。
- 推荐顺序为：代数更少、配种节点更少、不同中间帕鲁更少、亲本 ID 字典序。
- 选择配种节点可查看保持该节点代数、起点集合和无环约束的替代配方。
- 同时提供可缩放/平移的图形画布和完整文本步骤。

### 状态反馈

必须区分：起点为空、目标不在配方矩阵、不可达、指定 N 低于最少代数、N 代内无无环方案、超过当前可视化上限。

## 5. 管理员配置

- 顶部提供无口令的本地“管理员配置”页。
- 指定代数上限默认 6，可设为 1–12 整数；12 为代码硬上限。
- 保存到 `paltools.admin-config.v1`，支持保存与恢复默认值 6。
- 缺失、损坏、非整数或越界时回退到 6，并在配置页提示。
- 降低上限后，路径页超出的 N 立即收缩并重新计算。
- 最少代数计算不受展示上限影响；若超过上限，只显示准确代数，不构造画布。

## 6. 非功能验收

- 正反向常规查询目标低于 100ms。
- 典型六代内路径目标低于 500ms；管理员提高到 12 代时目标低于 2 秒。
- 路径计算在 Web Worker 中运行，旧请求结果不得覆盖新请求。
- 断网时图鉴、技能、掉落、正反向查询和路径规划均可用。
- 常见桌面宽度与 768px 可用；主要控件支持键盘操作。
- `npm test`、`npm run typecheck`、`npm run data:validate`、`npm run build`、`npm run package:exe` 全部通过。

## 7. 边界

不处理个体数量、孵化时间、蛋糕成本、被动继承概率、存档导入/修改、账号、云同步或运行时遥测。
